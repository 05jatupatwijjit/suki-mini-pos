# Functional Requirement: Suki Mini POS

เมนูและราคา: ชุดหมู 199 บาท, ชุดเนื้อ 249 บาท, น้ำดื่ม 20 บาท

## FR-01 แสดงเมนูและราคา
**ข้อกำหนด:** ระบบแสดงเมนู 3 รายการพร้อมราคา และจำนวนปัจจุบันของแต่ละรายการ

**Expected Result:** เมื่อเปิดหน้าเว็บ เห็นชุดหมู 199, ชุดเนื้อ 249, น้ำดื่ม 20 บาท ครบทั้ง 3 รายการ

**เกณฑ์ตรวจรับ**
- มีสินค้า 3 รายการ ชื่อและราคาถูกต้อง
- แต่ละรายการมีปุ่ม + และ − และแสดงจำนวนเริ่มต้นเป็น 0

## FR-02 เพิ่ม/ลดจำนวนสินค้า
**ข้อกำหนด:** พนักงานกดปุ่ม + เพื่อเพิ่ม และปุ่ม − เพื่อลดจำนวนสินค้าทีละ 1

**Expected Result:** จำนวนของรายการนั้นเปลี่ยนทันที และไม่ต่ำกว่า 0

**เกณฑ์ตรวจรับ**
- กด + หนึ่งครั้ง จำนวนเพิ่มขึ้น 1
- กด − หนึ่งครั้ง จำนวนลดลง 1
- กด − เมื่อจำนวนเป็น 0 จำนวนยังเป็น 0

## FR-03 แสดงตะกร้า
**ข้อกำหนด:** ระบบแสดงรายการในตะกร้าแบบใบเสร็จ ได้แก่ ชื่อ จำนวน ราคาต่อหน่วย และราคารวมของแต่ละรายการ รายการที่จำนวนเป็น 0 ไม่แสดง และจำนวนในตะกร้าคงอยู่เมื่อรีเฟรชหน้าเว็บ

**Expected Result:** ตะกร้าตรงกับจำนวนที่เลือก เช่น ชุดเนื้อ x2 = 498 และข้อมูลไม่หายหลังรีเฟรช

**เกณฑ์ตรวจรับ**
- ตะกร้าว่างแสดงข้อความ "ยังไม่มีรายการ"
- รายการที่ลดจนเหลือ 0 หายออกจากตะกร้า
- รีเฟรชหน้าเว็บแล้ว รายการและจำนวนยังคงเดิม
- ถ้าอ่านข้อมูลที่บันทึกไว้ไม่ได้ ระบบเริ่มจากตะกร้าว่างและแจ้งว่าอ่านข้อมูลตะกร้าที่บันทึกไว้ไม่ได้
- ถ้าเบราว์เซอร์บันทึกข้อมูลไม่ได้ ระบบใช้งานต่อได้และแจ้งว่าไม่สามารถบันทึกตะกร้าได้

## FR-04 คำนวณยอดรวม
**ข้อกำหนด:** ระบบคำนวณยอดทั้งหมดจากผลรวมของ (ราคา x จำนวน) ทุกรายการ และอัปเดตทันทีเมื่อจำนวนเปลี่ยน

**Expected Result:** ยอดทั้งหมดถูกต้องเสมอ

**เกณฑ์ตรวจรับ**

| การทดสอบ | ผลที่คาดหวัง |
|---|---|
| ชุดหมู 1 + น้ำดื่ม 1 | 219 บาท |
| ชุดเนื้อ 2 | 498 บาท |
| ตะกร้าว่าง | 0 บาท |

## FR-05 ล้างตะกร้า
**ข้อกำหนด:** พนักงานกดปุ่มล้างตะกร้า ระบบแสดงหน้าต่างขอยืนยันก่อนล้าง

**Expected Result:** เมื่อยืนยัน ตะกร้าว่างและยอดรวมเป็น 0 บาท เมื่อยกเลิก ตะกร้าคงเดิม

**เกณฑ์ตรวจรับ**
- กดล้างตะกร้าแล้วมีหน้าต่างยืนยัน โดยตะกร้ายังไม่เปลี่ยน
- กดยืนยัน: รายการว่าง จำนวนทุกเมนูเป็น 0 ยอดรวม 0 บาท
- กดยืนยันแล้วรีเฟรชหน้าเว็บ ตะกร้ายังว่าง (ข้อมูลที่เก็บไว้ถูกล้างด้วย)
- กดยกเลิก: รายการและยอดรวมไม่เปลี่ยน
