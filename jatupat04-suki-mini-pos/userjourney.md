# User Journey: Suki Mini POS

**ผู้ใช้:** พนักงานรับออร์เดอร์
**เป้าหมาย:** รับออร์เดอร์ลูกค้าและสรุปยอดรวมได้ถูกต้อง

## ขั้นตอนการใช้งาน

| Step | Action | System Response |
|---|---|---|
| 1 | เปิดหน้าเว็บ Suki Mini POS | แสดงเมนู 3 รายการพร้อมราคา (ชุดหมู 199, ชุดเนื้อ 249, น้ำดื่ม 20 บาท) และส่วนตะกร้า ถ้าไม่มีข้อมูลค้างอยู่ ตะกร้าว่างพร้อมข้อความ "ยังไม่มีรายการ" และยอดรวม 0 บาท ถ้าอ่านข้อมูลที่บันทึกไว้ไม่ได้ เริ่มจากตะกร้าว่างและแจ้งว่าอ่านข้อมูลตะกร้าที่บันทึกไว้ไม่ได้ ถ้าเบราว์เซอร์บันทึกข้อมูลไม่ได้ ระบบใช้งานต่อได้และแจ้งว่าไม่สามารถบันทึกตะกร้าได้ |
| 2 | ดูเมนูและราคา | เมนูแต่ละรายการแสดงชื่อ ราคา จำนวนปัจจุบัน และปุ่ม + / − |
| 3 | กดปุ่ม + ที่ชุดหมู 1 ครั้ง | จำนวนชุดหมูเป็น 1 ตะกร้าแสดงชุดหมู x1 ยอดรวมเป็น 199 บาท |
| 4 | กดปุ่ม + ที่น้ำดื่ม 1 ครั้ง | ตะกร้าเพิ่มน้ำดื่ม x1 ยอดรวมเป็น 219 บาท |
| 5 | กดปุ่ม + ที่ชุดเนื้อ 2 ครั้ง | จำนวนชุดเนื้อเป็น 2 ตะกร้าแสดงชุดเนื้อ x2 ยอดรวมอัปเดตตามรายการทั้งหมด |
| 6 | กดปุ่ม − เมื่อต้องการลดจำนวนหรือแก้ไขที่กดผิด | จำนวนของรายการนั้นลดลง 1 และยอดรวมอัปเดตทันที ถ้าจำนวนเหลือ 0 รายการนั้นหายออกจากตะกร้า (กด − ที่จำนวน 0 ไม่ติดลบ) |
| 7 | (หากเกิดขึ้น) รีเฟรชหน้าเว็บ | ตะกร้า จำนวน และยอดรวมยังคงเดิม |
| 8 | ตรวจรายการและสรุปยอดรวม แจ้งลูกค้า | ส่วนตะกร้าแสดงแบบใบเสร็จ: ชื่อ จำนวน ราคาต่อหน่วย ราคารวมของแต่ละรายการ (เช่น ชุดเนื้อ x2 = 498) และยอดทั้งหมดที่คำนวณถูกต้อง |
| 9 | กดปุ่มล้างตะกร้าเมื่อจบออร์เดอร์หรือเริ่มลูกค้าคนใหม่ | แสดงหน้าต่างขอยืนยันก่อนล้างตะกร้า ตะกร้ายังไม่เปลี่ยนแปลง |
| 10 | กดยืนยันการล้างตะกร้า | ตะกร้าว่าง จำนวนทุกเมนูเป็น 0 ยอดรวมกลับเป็น 0 บาท และข้อมูลที่เก็บไว้ถูกล้างด้วย |
| 10a | (ทางเลือก) กดยกเลิกที่หน้าต่างยืนยัน | ปิดหน้าต่าง ตะกร้าและยอดรวมคงเดิม |

## ตัวอย่างออร์เดอร์

| ออร์เดอร์ | ยอดรวมที่ถูกต้อง |
|---|---|
| ชุดหมู 1 + น้ำดื่ม 1 | 219 บาท |
| ชุดเนื้อ 2 | 498 บาท |
| กดล้างตะกร้าแล้วกดยืนยัน | 0 บาท |
| กดล้างตะกร้าแล้วกดยกเลิก | ยอดเดิมไม่เปลี่ยน |
